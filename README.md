# mzizi-lang

Phase 0 of the Mzizi Rust-framework research charter — see [`CHARTER.md`](./CHARTER.md) for
the full thesis, phasing, and the ownership/interim-location note.

**Status: not started.** This directory exists to hold Phase 0's compiler/syntax prototype.
The syntax and type system themselves — the actual research bet — have not been designed yet
(charter §7). `compiler/` is an empty crate placeholder, not a starting implementation.

```
mzizi-lang/
├── CHARTER.md          # the charter, plus resolved/open decisions
├── compiler/           # empty crate placeholder — no syntax designed yet
└── benchmarks/         # Phase 0 benchmark harness — mechanics not yet designed
```
